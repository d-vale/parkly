# 🅿️ Parkly

**Trouvez votre place de parking en temps réel, intelligemment.**

Parkly est une application innovante qui affiche en temps réel le nombre de places disponibles dans les parkings publics et identifie précisément quelles places sont libres. Grâce à un algorithme prédictif intelligent, l'application anticipe le taux d'occupation en fonction des événements à proximité et de l'historique de fréquentation.

## ✨ Fonctionnalités

- **Disponibilité en temps réel** : Consultez instantanément le nombre de places libres dans les parkings publics
- **Localisation précise** : Visualisez exactement quelles places sont disponibles
- **Prédictions intelligentes** : Un algorithme analyse les événements locaux et les tendances d'occupation pour prédire la disponibilité future
- **Anticipation** : Planifiez votre déplacement en vérifiant la disponibilité à une date et heure précises


## 🚀 À propos du projet

Ce projet personnel est né d'une frustration quotidienne : perdre un temps précieux à chercher une place de parking. En tant que développeur passionné, j'ai saisi l'opportunité de créer une solution pratique tout en explorant de nouvelles technologies et en perfectionnant mes compétences techniques.

Le projet est actuellement en développement actif, avec de nouvelles fonctionnalités ajoutées régulièrement.

## 🛠️ Stack technique

- **Backend** : PHP (Laravel)
- **Frontend** : Vue.js
- **Base de données** : MySQL
- **Containerisation** : Docker


## 📦 Installation

### Cloner le repository

```bash
git clone https://github.com/d-vale/parkly.git
cd parkly
```

### Démarrer avec Docker

```bash
docker compose up --build
```
